# Shared garden / orchard design baseline

Checkpoint for parallel design work, October 2. Current branch is `fix/editor-startup-terrain-catalogue`, HEAD `093e6fdbe1e6e1c1f814050e29454e07786fec14`. Existing uncommitted gameplay/cleanup work is retained. This turn authors static designs and notes only.

| Topic | Actual current facts | Open design issue |
| --- | --- | --- |
| Scope and UI | User chooses the preferred main desktop style, Garden/Orchard switch and separate Beds, Progression and Town views. Narrow is lower priority. Barkley/Gill systems are parked for this discussion. | Final controls/content of the later Orchard state after its mechanics are chosen. |
| Available code | `FarmService` is explicitly installed only in the isolated development scene; production Main has no service. `FarmCommands` binds two original beds and `seed.radish`. | No full seventeen-crop or Orchard gameplay implementation. |
| Implemented prototype loop | One pack plants one finite batch; elapsed growth settles online/offline; ready harvest empties it. Duration is captured at planting. The current slice has no watering or farm-harvest Farming XP. | These prototype choices do not settle the discussed watering visits, growing XP, automatic watering or level-based speed ideas. |
| Prototype tuning | `FarmTuning`: 30 minutes, 10 base Radish, 10 Log + 20 Stick preparation. `FarmService`: 0.1 development Radish-pack roll. | These source values are development settings, not approval of final growth/yield/build prices. The shared design-session briefing records 10% behind a farming quest as direction; exact quest, matching/global membership and adventure Echo eligibility still need definition. |
| Crop footprint | Accepted V4 direction: original frontage/farmers/windmill retained, back fence lowered from Y10 to Y6, proper fence corners/ends/gates, both later fields have dual path approaches. Six crop-bed geometry is previewed. | Three 2→4→6 build stages are the prior proposed content sequence; their precise unlock requirements/prices are not approved by the visual acceptance. No new Barkley system is designed in these screens. |
| Seed discovery | Packs are fresh discoveries for everyone through new-version plant pools; old crop access grants/reveals no packs. No Alter Echo compensation. Prepared art has 22 known packets plus one shared unknown. | Seventeen gameplay crop keys do not map automatically to those 22 art families. |
| Crop art | Current bindings include Radish→Eggplant art, Lettuce→Cabbage, Pepper→Beet and Turnip→Radish. The isolated town Radish presentation binds real Radish art locally. Cucumber's adventure sequence needs explicit semantic ordering review. | Full town recipe/icon/world-art manifest; no silent resource-key renaming or inherited mismatches. |
| Existing skill | Adventure Farming already grants skill XP. `Farming.asset` uses `10 × level^1.5`; current task speed is `1 + 0.01 × Farming level` before other modifiers. Radish requires skill level 1; Corn 7. | These are hero adventure-skill facts, not an approved Flora/Tillman XP curve, benefit or town-growth modifier. |
| Twins progression | Latest direction is the twins' own progression rather than per-crop mastery. | What level does, shared/separate XP, earning events, thresholds, benefits and perks remain undecided. New screens omit the numeric header. |
| Orchard | User requires a separate area, preserving crop beds, with later unlock. Actual SmallSapling/YoungTree/MatureTree world sprites and a fruiting apple tree exist; separate six/eight-tree space previews exist. | Final capacity, exact later gate, inputs, planting/care/fruiting/harvest cycle, fruit sinks and XP. A fresh scan of all 75 current Resource Item assets found no Apple/Pear/Peach/Orange/Plum/Cherry resource keys. The recorded orchard audit establishes world art, not an implemented fruit-harvest loop. |
