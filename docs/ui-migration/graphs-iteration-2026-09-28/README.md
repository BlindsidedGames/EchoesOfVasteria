# Graphs redesign - 28 September 2026

`graphs-final.png` is the 1280x720 resources/totals view using the disposable developed profile. All maps plus five individual map filters are available. Metrics are Resources, Tasks, Kills, Duration and Distance; the pre-existing legacy GraphMode API remains supported without modifying its serialized enum. Totals is the default; per-minute rates are available only for Resources/Tasks/Kills.

Each rate uses the saved unscaled run Duration: value * 60 / Duration. Runs with Duration <= 0 are excluded only in rate mode, with an explicit omission count. The average line/summary is the arithmetic average of the plotted per-run values, not a combined-throughput estimate. Best is the maximum plotted value; Duration uses the label Longest. Samples are explicitly limited to the retained last 50 runs across all maps. No history is invented or backfilled, and no gameplay accounting is changed.

The chart uses a linear zero baseline, quiet quarter-height grid lines, visible scale labels, chronological run-number endpoints and outcome colours with a legend. Hover/focus previews a run; click/tap pins it, and leaving returns to the pinned selection. Details remain below the chart and include map, outcome, duration, distance, tasks, resources, bonus resources, kills and damage dealt/taken. Bonus resources remain a separately labelled detail rather than a second coloured overlay. Selection outlines the actual bar instead of tinting its full height (the latter was removed after visual inspection because it resembled a false tall bar).

`checks-graphs.txt` passed metric/rate availability, per-map bar counts, known rate calculations, undefined zero-duration rate handling, pinned selection, all eight detail measures, smaller landscape bounds, and local empty/single-zero-run states. The phone capture is 844x390 despite its filename. The empty-history fixture used an independent local list, without clearing the actual tracker or save. Physical touch, portrait layout, localization and increased text scale remain unverified.

Validation used an isolated developed profile, offline/save/feedback guards, timeScale 0, VSync disabled and 30 FPS. Temporary guards were restored byte-for-byte (restoration.json), normal project identity restored, and Play mode stopped. No real saves/cloud progression were changed. Harnesses remain ignored under Library.
