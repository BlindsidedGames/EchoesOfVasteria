# Cute Fantasy Icons — sliced originals

The active collection contains nine original 16x16 sprite sheets and the publisher license. Individual PNGs and enlarged 32x32/64x64 variants were archived outside both repositories before removal from the active collection. The purchased premium ZIP is retained outside Unity.

Each sheet imports as Sprite (Multiple), 16 pixels per unit, Point filtering, no mipmaps, no compression, no non-power-of-two scaling, Clamp wrapping, and full-rectangle sprite meshes with centred pivots. Every cell is 16x16 with zero padding/offset. Unused cells are excluded.

All 6,982 slice names retain Kenmi's original individual-PNG stems, for example Farming_16x16_Icon_1. Names and cell positions were matched by exact RGBA pixel content, not assumed file order. Farming now has 205 classification suffixes: 33 user-selected labels and 172 inferred labels pending general review. Icon 171 is BirchSeed, as selected by the user. FarmingClassifications.json records candidates, uncertainty and reasoning. IconSheetMap.json records original names, sheet-relative paths, bottom-origin Unity pixel coordinates, and stable sprite IDs. Future agreed labels can be appended without changing the sprite ID. Unity .meta files contain the actual imported sprite definitions and must travel with the sheets.
