# In-run HUD design reference

Open **Tools → UI → Run HUD Prototypes** while Unity is in Play mode.

**Compact pop-out** shows a slim health strip and a Stats button. Click Stats to open or close a separate panel above it, with labeled offensive and defensive stats and right-aligned values. The health strip stays in place.

**Current** restores the existing HUD. Closing the prototype window also restores it. This editor-only preview uses live values and existing icons; it does not replace the production HUD or change gameplay.
